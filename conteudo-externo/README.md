# Conteúdo externo para ampliar os resultados de marca

Estes textos são versões originais, não cópias dos artigos do site. Publicar em contas autênticas e completas, sempre vinculando para a página mais relevante do site oficial.

Ordem recomendada:
1. LinkedIn — perfil pessoal e dois artigos.
2. Medium — perfil com biografia consistente e dois textos.
3. Substack — newsletter com página “Sobre” e dois textos.
4. YouTube — vídeo curto de apresentação e vídeos dos projetos.

Não publicar tudo no mesmo dia. Use uma cadência semanal e adapte título, introdução e imagem para cada plataforma.
